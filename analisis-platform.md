# Analisis Perbandingan Platform Web, Desktop, dan Mobile

## 1. Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | Python, Java, C# | Kotlin, Java, Swift |
| Arsitektur | Client-server | Aplikasi berjalan pada sistem operasi komputer | Aplikasi berjalan pada perangkat mobile |
| Cara distribusi | Melalui browser dan alamat website | Melalui installer atau toko aplikasi | Melalui Play Store, App Store, atau file instalasi |
| Keunggulan | Mudah diakses tanpa instalasi khusus | Dapat memanfaatkan fitur komputer secara langsung | Praktis digunakan dan mendukung fitur perangkat mobile |
| Keterbatasan | Bergantung pada browser dan dapat bergantung pada internet | Perlu penyesuaian dengan sistem operasi | Memiliki keterbatasan ukuran layar dan spesifikasi perangkat |
| Contoh aplikasi | Google Docs, YouTube | Microsoft Word, Visual Studio Code | WhatsApp, Google Maps |
