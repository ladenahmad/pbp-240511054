# Refleksi

## 1. Platform mana yang paling menarik untuk dipelajari? Mengapa?

Platform yang paling menarik bagi saya untuk dipelajari adalah Web karena dapat diakses melalui browser dan digunakan dari berbagai perangkat. Saya ingin mempelajari dasar pengembangan Web menggunakan HTML, CSS, dan JavaScript. Sebelum membuat aplikasi, saya perlu menyiapkan tools pemrograman seperti Visual Studio Code, Node.js, dan NPM agar proses menulis serta menjalankan kode dapat dilakukan dengan baik.

## 2. Apa tantangan terbesar saat setup environment?

Tantangan terbesar dalam setup environment adalah memastikan semua tools yang dibutuhkan telah terinstal dan dapat dijalankan melalui terminal. Saya perlu memeriksa versi Git, Node.js, NPM, dan Java JDK menggunakan perintah yang ditentukan. Selain itu, saya perlu membuat repository GitHub dengan nama `pbp-[NIM]` dan melakukan clone repository tersebut ke komputer. Jika ada perintah yang tidak dikenali atau proses instalasi mengalami kendala, saya perlu mencari penyebabnya terlebih dahulu. Android Studio juga dapat menjadi tantangan karena ukuran instalasinya cukup besar, sehingga instalasinya mungkin perlu dilakukan kemudian dan dilaporkan sesuai instruksi tugas.

## 3. Bagaimana rencana Anda mengatasi tantangan tersebut?

Saya akan menginstal tools satu per satu dengan mengikuti panduan instalasi resmi. Setelah itu, saya akan membuka terminal atau CMD dan menjalankan perintah `git --version`, `node --version`, `npm --version`, serta `java -version` untuk memastikan tools terpasang dengan benar. Saya juga akan mengambil screenshot hasil perintah tersebut sebagai bukti. Selanjutnya, saya akan memastikan repository GitHub bernama `pbp-[NIM]` sudah dibuat dan berhasil di-clone ke komputer. Jika menemui kendala, saya akan membaca pesan error, memeriksa konfigurasi, dan mencari solusi melalui dokumentasi resmi atau meminta bantuan dosen. Jika Android Studio belum dapat dipasang karena ukuran file, saya akan melaporkan kendala tersebut.
